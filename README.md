# 🌟 Project Overview
This project is a responsive landing page for Maple Leaf Books, a cozy neighborhood bookstore that promotes curated titles and community events.

The design was first created in Figma (desktop, tablet, and mobile views) and implemented using HTML5 and CSS3, following user-centered design and accessibility principles.



# 💻 Features
- Responsive layout for desktop, tablet, and mobile viewports  
- Accessible color contrast and visible focus outlines  
- “Skip to main content” link for keyboard users  
- Semantic HTML structure (`header`, `main`, `footer`, `section`)  
- Alt text for every image  
- “Shop Online” and “Visit Our Store” call-to-action buttons  
- Clean, elegant typography using Playfair Display* and *Inter*  

---

# 🧩 Technologies Used
- Figma – UI design and layout planning  
- HTML5 – page structure and semantics  
- CSS3 – styling, layout, and responsiveness  
- Google Fonts – typography customization  
- GitHub Pages – hosting and deployment

# ♿ Accessibility Features
- Skip link for keyboard navigation  
- High contrast text for readability  
- Descriptive alt text on all book cover images  
- ARIA labels for navigation and section headers  
- Mobile-friendly tap targets** for buttons and links
